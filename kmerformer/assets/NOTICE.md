# Tokenizer attribution

`ntv2_6mer.json` preserves the token ordering of `vocab.txt` from
InstaDeepAI/nucleotide-transformer-v2-500m-multi-species, revision
`06615c1660c892fc199840c18123f8385b3542a8`. Its source SHA-256 is recorded in the JSON.
The conversion changes serialization only, retaining all 4,107 token strings and IDs.
