# Exact 13-mer vocabulary attribution

The paper's `vocabulary.txt` is the MetaTransformer canonical 13-mer vocabulary.
Source: Alexander Wichmann, *MetaTransformer embedding tables* (2023),
https://doi.org/10.5281/zenodo.7594864, `vocab_13mer.txt.gz`.

The dataset record specifies **CC BY 4.0**:
https://creativecommons.org/licenses/by/4.0/.
The delivered text is uncompressed; token ordering is retained.
The source record and local vocabulary checksum are in `exact13_provenance.json`.
Tokenizer special tokens are added by the KmerFormer implementation.

The upstream code repository is https://github.com/alexwichma/MetaTransformer.
Its software licence and the vocabulary dataset's licence are separate records.
KmerFormer's code licence does not replace the dataset terms.
