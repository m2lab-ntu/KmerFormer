## Numerical reference

The installed PyTorch 2.6 fused CUDA encoder changed maximum predicted softmax
scores by up to 0.0021 on the 16-read primary example; all class IDs agreed.
Using the unfused FP32 path reduced the maximum score difference below 1e-6.
The new prediction reference uses that path, with highest matrix-multiply
precision, and restores the caller's runtime settings afterwards. Historical
paper throughput measurements and reported accuracies retain their own protocols.

## Release state

Draft GitHub release `v0.2.0rc1` holds four model bundles; their download
records were registered in `kmerformer/assets/models.json` and later removed
while the weights are withheld. Branch CI passed at both
`54f57ef` and `19bdf39`. The 2026-09-18 delivery pass replaces the earlier
wheel and `54f57ef` code ZIP with a wheel and code ZIP from the same delivery
commit; the Zenodo preparation tool verifies their source parity. The repository
was made public on 2026-09-25. The model bundles are not publicly released: the
download records were removed from `models.json`, and the draft release stays
unpublished. The four KmerFormer weight files use Apache-2.0;
tokenizer licences are recorded separately and retained in full within each
bundle. Licensing updates preserve the weight, tokenizer, label and
configuration checksums. The evidence collection supports
rescoring existing predictions. Full raw training pools, genome downloads and
all historical simulation/selection drivers are not included in the code
archive; see [missing assets](../MISSING_ASSETS.md).
